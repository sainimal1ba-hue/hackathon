# CLASH OF COMMITS — WAR ROOM

**This repo is the team's main memory.** Everything decided for [Clash of Commits](https://clash-of-commits.ieeerasvitc.in/problems) (IEEE RAS VITC — 24-hour hackathon, 4–5 Dec 2026, clans of 4–5) lands here.

## Command intent
Pick **one** software-domain problem, then design a feature stack that is **what everyone else will build + what nobody else will think of**. Nothing generic survives the arena.

## Decision protocol — gladiator wars
Topics and features are not decided by committee. Sub-agents are spawned as gladiators, each fights to the death for a position, and emperor-agents render the verdicts. All battle transcripts are committed here as evidence.
