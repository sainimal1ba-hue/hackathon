# HEROKILL — Image Generation Prompts

*The complete asset list for the winning design (THE OPERA). Generate all seven with a text-to-image model in the first two build hours, then one style pass across all at hour 20. These images serve the commercial website; the same library doubles as deck and social material.*

## Style lock (append to EVERY prompt)

> cinematic dark theater, volumetric fog, single rim light, deep black background, 35mm, film grain, no text, no watermark, no people

## Usage notes

- Palette discipline in-image: only RED CODE `#FF1E27`, Rise Green `#00FF7B`, Seal Gold `#C9A227` accents on near-black `#050505` — one accent per image, gold only on certificate motifs.
- No legible text should appear in generated images; all type is set in the DOM (Anton / Space Grotesk / JetBrains Mono), so the brand voice stays exact.
- Acts 01, 05 and the OG card are the three must-haves if image time collapses; the rest can be replaced by the pure-void treatment.
- Generate at 2x resolution, compress to WebP for the site, keep PNG for deck/print use.
