## CLAIM
- **Bottomless feature surface (C1):** deploys, live logs, metrics, rollback, domains, quotas, health checks — every coding hour in this problem mints a visible, demoable artifact.
- **This is our life, weaponized (C2 + C6):** we already run 98 green tests, GitHub Actions CI, and Docker deployments. PS-WEB-01 is our discipline turned into a product — zero new stack to learn while rivals gamble.
- **Built-in theater (C3):** `git push` → live HTTPS URL in 60 seconds → we sabotage our own app on stage → health checks scream → auto-rollback to green. The audience doesn't watch a demo; they feel the save.
- **Inverted crowd risk (C5):** the AI trio lures 100+ clans; Docker-heavy backend work scares casuals off. Maybe six clans pick this — and half drown in container-in-container hell. Quiet lane, loud demo.
- **Deep differentiation room (C4):** the obvious build is a "deploy button"; the rollback timeline scrubber and per-PR preview URLs are ours alone.

## THE BUILD
1. **Push-to-deploy:** paste a repo → containerized, routed via reverse proxy, live URL in under a minute.
2. **Live log theater:** WebSockets streaming colored stdout in a real terminal feel.
3. **The rollback moment:** deploy a poisoned commit → auto-detect → auto-revert → scrub through every version on a timeline UI.
4. **Instant custom domains** with automatic SSL.
5. **Resource cage:** per-app CPU/RAM quotas; a runaway app strangled live.
6. **Resurrection:** kill the container on stage — platform detects and restarts it.
7. **In-browser shell** exec into the running container.
8. **Test-gated deploys** — our 98-test discipline mirrored: no green, no live.
