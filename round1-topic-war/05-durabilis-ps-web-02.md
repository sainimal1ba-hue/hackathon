## CLAIM
- **Feature Surface** — every layer ships a screen: canvas, node palette, queue inspector, execution ledger, crash timeline, dead-letter triage. Ten-plus demo-able features, one coherent product.
- **24H Feasibility** — React Flow + Node + Redis + Docker IS our stack. No training runs, no chains, no OS hooks. We demo; we don't narrate.
- **Demo WOW** — we kill our own engine ON STAGE: `kill -9` mid-workflow, and it resurrects at step 7 of 9, firing the email exactly once. Audiences vote for resurrections.
- **Differentiation Room** — the obvious build is drag-drop-plus-queue. Ours: an audience-triggered CHAOS BUTTON, ghost-replay of the crash, visible idempotency keys, dead-letter triage.
- **Team Fit & Crowd Risk** — 98 green tests, CI, Docker: only we can *prove* "unbreakable." Durability scares tourists; the herd stampedes to AI and voice.

## THE BUILD
1. React Flow canvas, 15-node palette — HTTP, email, delay, condition, script.
2. Durable Redis queue + live execution ledger, every step timestamped.
3. On-stage `kill -9` → workflow resumes precisely, zero duplicate side effects.
4. CHAOS BUTTON: the audience picks the victim — queue, runner, or node.
5. Ghost replay: scrub the timeline to the moment of death, inspect state.
6. Sandboxed Docker runner: per-step logs, retry/backoff policy editor.
7. Dead-letter triage screen: fix, then re-run only the failed steps.
8. CI board glowing green — a live test suite proving resume correctness.
