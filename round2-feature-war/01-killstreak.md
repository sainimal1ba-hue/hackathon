# Round 2 — School 1: KILLSTREAK「弑容器者」

*Feature War gladiator — 路线：死亡系统（混沌注入 · 红灯警报 · 验尸引擎 · 复活仪式）*

---

**KILLSTREAK「弑容器者」**

**【出战宣言】**
他们造云，我造云的葬礼。永远在线的平台没人记得——观众只为"亲手毁灭、一键赦免"的六十秒起立。我独占整套死亡系统：武器、警报、验尸、复活，一条龙。毁掉自己的作品再亲手救活它，才是最诚实的产品证明。

**【TABLE STAKES】**
- 混沌注入四型：毒代码／依赖爆炸／内存泄漏／kill -9，全部真实 Docker+cgroup 事件，不是 setTimeout 假装。
- 健康检查：轮询＋连续失守门限判定，绿灯呼吸→红灯频闪，逻辑套用我们 98 个测试的既有纪律。
- 自动回滚：绿色镜像常驻缓存，回滚 <10 秒，比现场 git revert 快四倍。
- 死亡记录：exit code 法医学（137=OOM、143=SIGTERM），别人只留一行 "exited"，我们出具死因。
- 零外网依赖：警报、注入、回滚全在本地，会场 Wi-Fi 死透也照样开演。

**【SIGNATURE MOVES】**

**① CHAOS PANEL／混沌武器库**
骷髅武器卡一排，按下即真实处刑容器。
- 想不到：别人把故障当 bug 藏，我们把故障做成产品入口——没人敢给观众一把上膛的枪。
- 可行性：真实 Docker 事件驱动（工程）；卡片 UI 半小时（包装）。
- demo：第一枪交给评委亲手扣扳机。

**② RED CODE／红灯警报**
健康检查失守→全屏红光频闪＋预录警报长鸣，投影染红整个会场。
- 想不到：别人弹 toast，我们让平台惨叫——警报是感官事件，不是通知。
- 可行性：轮询＋门限（工程）；CSS 红闪＋本地音频（包装）。
- demo：红灯亮起，全场屏息，然后掌声。

**③ AUTOPSY ENGINE／验尸报告**
死亡即出具 Death Certificate：死因、凶手、遗言（末三行日志）、享年，编号入册。
- 想不到：日志查看器遍地都是，法医叙事只有一份——把运维排障变成黑色幽默。
- 可行性：docker inspect＋exit code 映射（工程）；证明卡片排版（包装）。
- demo：当场宣读"3 号证明：死于 OOM，凶手 kill -9，享年 4 分 12 秒"。

**④ RESURRECTION RITE／复活仪式**
连续失守→自动回滚绿色版本→容器重生→心跳回归时间线，一键赦免亲手犯下的罪。
- 想不到：回滚人人会写，没人做成赦免仪式——罪恶感＋解除感是成瘾回路。
- 可行性：绿色镜像预烤＋回滚脚本（工程）；复活动画（包装）。
- demo：红灯熄灭、绿灯呼吸回归，全场松一口气——上瘾点在此。

**【KILL SHOT】JUDGE'S TRIGGER／评委之铳**
请评委亲手按下处刑按钮：他们杀掉的平台，十秒后被同一只手复活。
- 致 ARCHITECTUS：你搭好舞台却没写剧本——没有死亡，你的回滚永远无法登场；你的扩容滑块挪的是数字，我的按钮终结的是性命。
- 致 CHRONOS：你的时间线只是坐标纸，是我在你轴上钉下墓碑，你才有东西可拖——没有尸体的时间旅行是空转。
- 致 FURIOSA：你的终局高潮只能由我递上——没有葬礼，何来复活。
为什么赢：观众把票投给自己亲手参与的高潮。

**【RISK REPORT】**
最大风险：毁灭失控或复活失败——容器死在台上不回来，demo 当场暴毙。对策：所有武器锁进 cgroup 笼子（内存上限、隔离网络，泄漏只烧死容器不伤宿主）；保底绿色镜像常驻；死而复生循环进 CI 反复排练；另备现场复活脚本作 dead-man switch。
