# Round 2 — School 4: FURIOSA「暴怒者」

*Feature War gladiator — 路线：demo 剧场（三分钟节奏表 · 冷启动 · 借来的手 · 复活倒计时 · 声浪处刑）*

---

**FURIOSA「暴怒者」｜Round 2 的王座不颁给功能，颁给心跳**

**【出战宣言】**
评委只给你三分钟记忆，观众不投功能票，投心跳票。ARCHITECTUS 造了城，KILLSTREAK 造了死亡系统，CHRONOS 造了时间轴——但没有一个人的方案能让全场呼吸在同一秒停止。那是我的地盘。我不新造功能，我把功能排成一场戏：开场即战场，死亡有仪式，复活有倒计时。三分钟节奏表：**0:15 点亮全墙｜1:00 评委部署｜1:40 评委下毒｜2:00 复活倒计时｜2:40 死亡回放｜2:55 声浪处刑**。

**【TABLE STAKES】**
- **git push 即部署**：15 秒黑场冷启动，比任何 PPT 开场快三分钟。
- **健康检查报警**：本地音频警报 + 状态墙整面变红——先听见死亡，再看见日志。
- **自动回滚**：绑定 30 秒倒计时，回滚从功能变成一场赛跑。
- **容器状态墙**：大字三色网格，三十米外可读；别人的仪表盘要凑近看。
- **自定义域名 + HTTPS**：预烤 wildcard 证书与本地 DNS override，离线不掉戏。

**【SIGNATURE MOVES】**

**① COLD OPEN｜冷启动**：黑场，巨幕终端只有一行 `$ git push`，状态墙逐格点亮一座数据中心。没人想到做"第 0 秒的舞台"——灯灭的瞬间全场自动安静。剧场包装是灯光音效，真实工程是每次点亮都为真部署。Demo 0:00–0:15。

**② THE HANDS｜借来的手**：笔记本递给评委，亲手 push 一个带他名字的版本，墙上亮起 "deployed by 评委"；两分钟后再请他亲手给它注入毒药。真实工程：push-to-deploy + 混沌面板；剧场包装：递出去的键盘。从创造者到刽子手，一人走完一条命环——这比任何扩容滑块更像一个真平台。

**③ RESURRECTION WINDOW｜复活倒计时**：flatline 长鸣、红墙、巨字倒计时压屏，全场跟我齐喊"十、九、八"，git revert，绿色脉冲复活，计时停在 00:07。没人想到参与感可以零基建：嗓子就是最古老的投票器。真实工程：SLA 计时 + 回滚 + 探测；剧场包装：声音与灯光。

**④ INSTANT REPLAY｜死亡回放**：时间线拖回案发前 30 秒，像体育慢镜重演死亡——哪条请求、哪次探测、哪次回滚。没人想到评委想看第二次死亡：时间轴不该是调试工具，该是重播键。真实工程：结构化日志回放；剧场包装：解说词。

**⑤ THE ROAR｜声浪处刑**：终局三容器三编号，"想看谁死就喊谁"，声浪最高者当场处决——让观众提前彩排一次投票。真实工程：混沌面板；剧场包装：一句口令。

**【KILL SHOT】**
**评委亲手下毒 + 全场齐声倒数 + 00:07 复活的那 60 秒。** 因为 ARCHITECTUS 的滑块是后台管理系统，KILLSTREAK 的警报是日志文件，CHRONOS 的轴是调试工具——没有剧场，功能再多也只是基础设施；而观众亲手处决、又亲眼看着复活的那一分钟，本身就是投给我们的选票。

**【RISK REPORT】**
最大风险：死亡系统现场真实翻车——毒药没毒死、回滚卡壳、评委不敢动手。对策：三层兜底——注入失败降级 `kill -9` 硬杀；回滚失败保底 healthy 标签一键复活；评委怯场，主持人接刀"我替您杀"。剧本第 18 小时冻结、只修不添；全幕彩排三遍并配计时员；音效、证书、repo 全部预烤本地，投影仪是唯一外部依赖。次级风险：全队埋头写功能无人排练——一人专任导演，冻结后全员进合成。

灯亮之前，我们已经在黑暗里赢了。
